IEEE 754 Float/Double Converter – Decimal ↔ Hex ↔ Binary Bit Pattern

Convert between decimal, hexadecimal, and IEEE 754 binary bit patterns for 32-bit float and 64-bit double. Visualize sign, exponent, and mantissa fields. Debug firmware register dumps, NaN/Inf values, and floating-point encoding.

What is IEEE 754?

IEEE 754 is the international standard for binary floating-point arithmetic, published by the Institute of Electrical and Electronics Engineers. It defines how computers store and compute with real numbers — used by every CPU, GPU, and microcontroller manufactured in the last 40 years. The standard specifies two primary formats: 32-bit single precision (float) and 64-bit double precision (double). Every value, including special cases like infinity and NaN, is encoded as a three-field binary pattern: a sign bit, a biased exponent, and a fractional mantissa.

Understanding the raw bit pattern behind a floating-point number is essential for embedded firmware development, debugging MCU register dumps, porting numeric code between platforms, and understanding rounding errors. This tool lets you explore any float or double by entering it as a decimal, hex, octal, or binary value — and shows you the exact IEEE 754 bit structure in real time.

How to Use This Tool

  1. Select Precision — Choose 32-bit Float or 64-bit Double using the tabs at the top.
  2. Enter a Value — Type into any of the four input fields. Decimal: enter any floating-point number (e.g. 3.14, -1.0, NaN, inf). Hex: enter the raw bit pattern as hex (e.g. 0x4048F5C3 for 32-bit). Octal: enter the octal bit pattern (e.g. 0o10022172703 for 32-bit). Binary: enter the 32- or 64-character bit string directly.
  3. Read the Bit Layout — The color-coded visualization shows each bit in its field: red for the sign bit, blue for the exponent, green for the mantissa.
  4. Read the Decoded Fields — The panel below the bit visualization shows the sign, biased exponent, actual exponent, mantissa fraction, and value class (Normal, NaN, Infinity, Zero, Denormalized).
  5. Copy — Click the copy icon next to any field to copy the value to your clipboard.

Common Use Cases

  • Firmware / Embedded Register Debugging: When a sensor, ADC, or DSP returns a 32-bit hex register value that represents a float, paste it into the Hex field to see the decoded decimal and bit layout. E.g. a temperature sensor may return 0x42280000 which decodes to 42.0°C.
  • NaN and Infinity Detection: Diagnose floating-point errors in math-heavy code. If a computation produces 0x7FC00000 (32-bit), the tool immediately identifies it as a Quiet NaN.
  • Cross-Platform Numeric Portability: Verify that a float serialized on a big-endian server matches the bit pattern expected on a little-endian ARM MCU.
  • Modbus / CAN Bus Float Decoding: Industrial protocols often transmit IEEE 754 floats in 32-bit registers. This tool helps you verify the encoding from the raw hex register dump.
  • Learning Floating-Point Internals: Step through special values like 0.1, 1.0/3.0, 16777216 + 1 to see how precision is lost at the bit level.
