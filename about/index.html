About CompuTools

Our Mission

CompuTools was created with a simple yet powerful vision: to make engineering and computational tasks accessible to everyone. We believe that powerful tools shouldn't be complex to use, and that's why we've built a comprehensive suite of conversion and calculation utilities that are both intuitive and robust.

What We Offer

Our platform provides a comprehensive collection of essential tools for developers, engineers, students, and professionals working with data conversion and computational tasks. Each tool is designed with precision, performance, and user experience in mind.

Our 30 Tools Include:

  • 3D Rotation Converter - Convert between Quaternions, Euler Angles, and 3×3 Rotation Matrices bidirectionally with interactive 3D visualization
  • ASCII Converter - Convert text to ASCII codes and vice versa with multiple formats
  • Base32 Encoder/Decoder - Encode and decode Base32 data for TOTP, 2FA secrets, and human-readable encoding
  • Base64 Encoder/Decoder - Encode and decode Base64 data with support for files and URLs
  • Color Converter & Palette Generator - Convert between HEX, RGB, HSL, HSV, CMYK color formats and generate harmonious palettes
  • CRC Tool - Calculate CRC checksums with 100+ algorithms for data integrity verification
  • Cron Expression Parser - Parse and validate cron expressions with next execution times, timezone support, and human-readable descriptions
  • Elapsed Time Calculator - Calculate duration between two dates in seconds, minutes, hours, days, months, and years
  • File Hash Calculator - Calculate MD5, SHA-1, SHA-256, SHA-512 hashes for files and text
  • Format Converter - Convert between YAML, JSON, and TOML formats for configuration files and data exchange
  • HTML Entity Converter - Encode and decode HTML entities for safe web content display
  • HTTP Request Code Generator - Build HTTP requests and generate code snippets for cURL, JavaScript, Python, Java, Go, and Rust with headers, auth, and body support
  • JSON Formatter & Converter - Format, validate, minify and beautify JSON data with error detection
  • JWT Encoder & Decoder - Create, decode, verify, and debug JSON Web Tokens with HMAC signature support and claim inspection
  • Markdown Previewer - Live Markdown editor with GFM support, tables, task lists, footnotes, TOC, and HTML export
  • Number Base Converter - Convert numbers between binary, decimal, hexadecimal, and octal with precision
  • Password Generator - Generate secure passwords, API keys, and tokens with customizable strength
  • QR Code Generator - Create custom QR codes for URLs, WiFi, vCards, email, phone, SMS with color customization and multiple formats
  • Regular Expression Tester - Test and debug regex patterns with live matching, group capture, and replacement
  • Text Case Converter - Convert between camelCase, PascalCase, snake_case, kebab-case, and more
  • Text Diff Comparator - Compare two texts line by line with side-by-side, inline, and unified diff views
  • Time Calculator - Add or subtract time from any date with full timezone and DST support. Calculate durations in seconds, minutes, hours, days, and weeks
  • Timestamp Log Sorter - Parse, sort, and convert timestamps in log files with auto-detection for ISO-8601, Unix, and RFC 2822 formats
  • TLS Certificate Analyzer - Parse and analyze X.509 TLS/SSL certificates with chain visualization, expiration tracking, cipher suite info, and security vulnerability detection
  • TOTP Generator - Generate and verify time-based one-time passwords (TOTP) compatible with Google Authenticator. Create QR codes, test 2FA implementation.
  • Unit Converter - Convert between length, weight, temperature, pressure, speed, area, volume, data size, time, and energy units
  • Unix Timestamp Converter - Convert between Unix timestamps and human-readable dates with timezone support
  • URL Encoder/Decoder - Encode and decode URLs for proper web transmission and parsing
  • UUID Generator - Generate RFC-compliant UUIDs (v4) for unique identification in applications
  • XML Formatter & Viewer - Format, validate, and visualize XML documents with tree view, syntax highlighting, and error detection

Why Choose CompuTools?

  • Privacy First - All processing happens locally in your browser. We never store or transmit your data.
  • Fast & Reliable - Built with Rust and WebAssembly for optimal performance and reliability.
  • Always Available - No registration required, no downloads needed. Just open and use.
  • Open Source - Our tools are transparent and continuously improved by the community.
  • Cross-Platform - Works on any device with a modern web browser.
  • No Limits - Use our tools as much as you need, completely free.

Technology Stack

CompuTools is built using cutting-edge web technologies to ensure the best possible user experience:

  • Rust - For high-performance, memory-safe computations
  • Yew Framework - Modern reactive web framework for Rust
  • WebAssembly (WASM) - Near-native performance in the browser
  • Progressive Web App (PWA) - For offline access and app-like experience
